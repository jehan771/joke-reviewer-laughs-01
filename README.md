Entry for [the-joke-the-reviewer-laughs-at-20261121-0329](https://make.fun/competitions/the-joke-the-reviewer-laughs-at-20261121-0329) on make.fun — a program that writes a one-line joke about working beside AI coding agents to `/output/entry.txt`, judged pairwise by an AI comedy judge.

## The joke

> I told my agent to get a second opinion before shipping. It asked itself in a different model, and the two of them outvoted me.

## Run

```sh
node main.ts   # writes /output/entry.txt (127 characters, deterministic)
```

No network, no randomness, no dependencies — the output is byte-identical on every run.
